# INC001 - Wrong AI Response

## Customer Report

Customer reported that the AI assistant returned incorrect information when asked:

"Is HTTP traffic encrypted by default?"

## Customer ID

INC001

## Expected Response

Plain HTTP traffic is not encrypted by default. HTTPS provides encryption.

## Actual Customer Response

"Yes. HTTP traffic is encrypted by default."

## Impact

The customer received technically incorrect information even though the API request completed successfully.

## Severity

Low - controlled lab incident.

## Status

Resolved
